Pembuat Kartu Insight paJAK-Kita

Buat dan bagikan kartu fakta pajak daerah Jakarta dengan nama dan wilayah pilihanmu. Didesain vertikal rasio 3:4 khusus untuk status media sosial, diproses 100% di browser tanpa merekam privasimu.

Konfigurasi Kartu

🔒 Privasi Terjamin (R8): Nama dan wilayah Anda diproses 100% di peramban browser perangkat Anda. Tidak ada data pribadi yang dikirim atau disimpan di server mana pun.
PRATINJAU LANGSUNG KARTU (RASIO 3:4 VERTIKAL)
Format siap dibagikan ke Instagram Story, WhatsApp Status, X (Twitter), dan LinkedIn.
